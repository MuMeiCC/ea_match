# 饿啊杯 ea_match — 0.1.5

独立比赛 Mod，源于 bisai9 的比赛规则和路线辅助，使用重新编写的计分与比赛记录。

## 使用

1. 将整个 `ea_match` 文件夹放在游戏的 `mods`(`steamapps\common\The Binding of Isaac Rebirth\mods`) 目录。支持带版本号或分支后缀的目录名，例如 `ea_match-1.0.0`、`ea_match-main`；`main.lua` 和 `metadata.xml` 应直接位于该目录下，字体目录 `resources/font/ea_match` 保持原名并保留全部文件。
2. 使用原版忏悔（Repentance／Repentance+）即可，无需安装 REPENTOGON。已安装它也可以使用，但不是必需依赖。
3. 关闭 `bisai9`、`bisai` 以及其他比赛规则 Mod，启用“饿啊杯 ea_match”。重启游戏，避免旧脚本或 Boss Rush 资源覆盖仍在内存里。
4. 新开局后，用向上／向下射击键选择终点，回车或主动道具键确认。
5. Esc 为游戏暂停；F4 映射到同一个原生暂停操作。F6 隐藏／显示计分板（含结算面板），比赛进行中隐藏时计时、计分照常进行，不影响终点选择菜单和错误提示。通关结算后不锁定角色操作，比赛成绩和总用时保持冻结。
6. 死亡界面直接重开，延续本场比赛的目标、总用时、死亡次数和历史成绩。返回主菜单再选择“新游戏”，则重新选择终点并开始一场新比赛，不继承上一场的用时和死亡次数。
7. 击败目标或精神错乱自动结束比赛。主菜单新开游戏允许开始新比赛，即使上一场尚未通关。局内按住 R 实际重开时，仅累计一次死亡，不结算本局成绩；自动延续当前比赛，累计时间不清零，历史最高分不变。轻点 R 未重开不计死亡。

没有实现角色禁用；选角限制由赛事人员执行。没有提供运行中修改目标、强制获胜或清空记录的命令。

## 已实现

- 移除普通存钱机及贪婪存钱机，不能捐款或炸出金币；不修改存档中的累计捐款数，其他机器不受影响。
- 3600 秒时间分，超时每秒继续倒扣；各局独立结算并取历史最高。
- Game Over 或局内 R 重开累计死亡次数，不扣分；正常死亡结算时血量固定为零，R 重开不结算。
- 道具仅按获取顺序计算当前持有的前 50 件，基础分、品质奖励、特殊道具奖励共用这 50 个名额；移除后后续道具补位。顺序随比赛记录保存。套装和隐藏成就独立判定。
- 新金币、血量、物品质量、特殊道具、金饰品、吞饰品、套装分值。
- 六终点，Hush 和完整 Boss Rush 额外奖励；无虚空直达传送门。
- 层 Boss 按逻辑层级去重，XL 两场分开；忘了我和五点骰子房不能刷同层 Boss。
- 楼层重新生成可再次获得隐藏房分；普通进出和退出续局不重复给分。
- 数据破解（C481）、遥控器、R 键、TMTRAINER 禁用。道具池重新抽取；直接生成或变形的底座替换为早餐，并拦截碰撞拾取和主动使用。绕过底座直接进入背包的道具，在玩家更新时移除并补为早餐。
- 局内 R 重开仅累计死亡次数，保留总用时、目标和历史成绩；普通的道具／角色复活保持原版行为。
- 正常退出保存、继续恢复；退出期间不计时。

## 验证与限制

原版使用持续背包快照记录道具获取顺序；同一次更新内新增的多个道具按份随机排序，只随机一次，结果及独立随机状态随比赛保存，不影响游戏自身随机数。同一更新内失去又获得同编号、且数量未变的情况无法从快照区分。旧存档没有历史获取顺序，首次读取时已有道具作为同一批随机排序；使用新规则建议新开比赛。

本次去除强制依赖后，只做 Lua 语法和接口检查；实际游戏效果由玩家实机测试。

仍需在游戏中验证：六条路线及 Boss 最终阶段、吞下重复金饰品、正常复活、真实五点骰子房／忘了我、F4 与 Esc 暂停、Boss Rush/Hush 原版入口和退出续局。

原版没有统一的“道具加入背包前”回调。合成或其他 Mod 直接给予禁用道具时，采用更新时清理；不能保证回滚清理前已触发的即时效果。若已安装 REPENTOGON，会额外使用其加入背包前拦截，但无它也能启动和计分。

饰品按原版接口的加权份数计算（普通 1、金色 2），每份单位 20 分，并扣除妈妈的盒子带来的额外倍率；包含吞下的饰品，不需要还原吞下饰品的颜色明细。

比赛每秒及关键事件保存记录。崩溃或强退只能恢复最近保存点；当前以正常退出续局为支持范围。存档种子不匹配或记录损坏时提示并停止计分，不静默开始另一场比赛。比赛记录对应当前 Mod 存档，比赛途中不要换存档槽或运行其他局。

控制台 `ea_status` 只读输出比赛记录，可用于排查。新比赛会替换上一场记录，请先保留需要的结算截图。

## 文件

- `main.lua`：回调、计时、状态、存档和界面。
- `scripts/rules.lua`：纯计分和跨局规则。
- `scripts/inventory.lua`：实际持有物品统计。
- `scripts/routes.lua`：路线便利。
- `tests/run_tests.py`：Python + lupa 的 Lua 5.3 测试入口。

原 bisai9 文件未修改，没有复制原版 `ambush.xml`，因此本 Mod 不会将 Boss Rush 改为贪婪战。字体沿用原项目所带 EID 字体资源。

接口依据：[原版 EntityPlayer](https://wofsauge.github.io/IsaacDocs/rep/EntityPlayer.html)、[游戏回调文档](https://wofsauge.github.io/IsaacDocs/rep/enums/ModCallbacks.html)。
